# 할 일

이 저장소에는 할 일 목록 파일이 없었다. 이번에 개선 제안 절만 만들었다.

## 개선 제안 (2026-10-23)

### 1. 스네이크 최고 점수가 프로그램을 끄면 사라짐

- **현상**: 최고 점수는 `Snake` 객체의 `self.best` 에만 있다(`src/snake.py:66`, `:110`). 주석은 판이 바뀌어도 남는다고 적었지만, 프로세스가 끝나면(`stop`, 패널 닫기) 사라진다. `snake.py` 와 `game.py` 에는 파일 저장 코드가 없다.
- **개선안**: 상태 폴더에 작은 JSON 파일로 저장하고 게임을 시작할 때 읽는다. 저장에 실패해도 게임은 계속 돌게 한다.
- **범위**: `src/snake.py`, `src/tetris.py` (게임 시작 시 읽기), `docs/usage.md`, `docs/usage.ko.md`
- **확인**: 점수를 낸 뒤 `stop` 과 `start` 를 거쳐 최고 점수가 남는지 본다. 실행하지 않았다. 세션 안에서만 남기는 것이 의도인지 먼저 정한다(확인 필요).
→ 의도: 최고 점수는 실행하는 동안만 기억하며 저장하지 않는다 (문서에 명시).

### 2. 게임 중 숫자 키 1~4 는 진행 중인 판을 버림

- **현상**: 게임 화면에서 `1`~`4` 를 누르면 현재 게임을 떠나 해당 게임을 새로 시작한다(`src/tetris.py:213-214`, 각 게임 루프의 `NUMBER_KEYS` 처리 `:250`, `:278`, `:304`). 진행 중인 판이 확인 없이 사라진다. 주석에는 "새로 시작한다"라고만 적혀 있다.
- **개선안**: 판이 진행 중일 때는 숫자 키를 무시하거나 확인 문구를 보인다. 지금 동작이 의도라면 `docs/usage.md` 에 적는다.
- **범위**: `src/tetris.py` (`NUMBER_KEYS` 처리), `docs/usage.md`, `docs/usage.ko.md`
- **확인**: 판을 시작한 뒤 숫자 키를 눌러 판이 어떻게 되는지 본다. 실행하지 않았다(확인 필요: 의도한 동작인지 먼저 정한다).
→ 완료: 게임 진행 중 숫자 키는 무시하고, 끝난 뒤에는 그 숫자의 게임으로 간다.

### 3. 호스트가 비정상 종료하면 `running` 표식이 남아 다시 시작하지 않을 수 있음 (확인 필요)

- **현상**: `cmd_host` 는 `running` 표식을 쓰고, 정상 종료할 때만 `finally` 에서 지운다(`src/plugin.py:136-158`). `cmd_start` 는 pane 이 살아 있고 `running` 표식이 있으면 아무 일도 하지 않는다(`src/plugin.py:105-106`). 호스트가 강제 종료되면 pane 은 셸 프롬프트로 남아 살아 있으므로 `start` 가 게임을 띄우지 않을 수 있다. 실행하지 않고 코드만 읽어 추정했다.
- **개선안**: `running` 표식에 호스트 프로세스 ID 를 적고, 그 프로세스가 살아 있을 때만 "이미 실행 중"으로 본다.
- **범위**: `src/plugin.py` (`cmd_start`, `cmd_host`)
- **확인**: 호스트 프로세스를 강제로 끊은 뒤 `start` 가 게임을 다시 띄우는지 본다(확인 필요).
→ 완료: 호스트가 죽은 뒤 남은 표식은 무시하고, 다음 시작에서 다시 띄운다.
